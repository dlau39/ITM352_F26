Summary:
If you run this python code it will load the data from the google drive url into a pandas DataFrame. It will then report how long the loading took and the number of rows that were loaded. It will also print a summary of the data such as the order, employee, region, customer, product, state, date range, sales, and the quantity. Below the summary is a menu where the user can pick between options: Show the first n rows, count employees by region, create a custom pivot table, or exit the program. The employee by region option will be hidden if its required columns are absent. It can also offer to export the displayed results as .csv file and asks the user for a file name when creating the file.
